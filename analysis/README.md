# 分析

这里计算集中度、做 BaTiS 与 UNCTAD 两套固定效应、分解伙伴个数和份额离散、计算 Oster 的 δ，并核对印度立法周的 GDELT 记录。

`panel_full.py` 写出 BaTiS 的年度集中度面板。`wto_hhi.py` 写出 WTO 2024 年集中度。`unctad_hhi.py` 与 `unctad_panel.py` 写出 UNCTAD 面板。`econ_batis.py`、`unctad_econ.py`、`unctad_econ2.py` 把报告用的回归表写到 `data/integrated/`。`07_gdelt_event.py` 写立法周日表。
